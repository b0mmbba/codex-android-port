Codex Android APK builds

1. CodexAndroid-arm64-v8a.apk
   For most modern real phones: Xiaomi, Samsung, Pixel, OnePlus and others.
   Use this first on a real phone.

2. CodexAndroid-LDPlayer-x86_64.apk
   For LDPlayer 64-bit and most modern Android emulators on PC.
   Use this first in LDPlayer.

3. CodexAndroid-LDPlayer-x86.apk
   For older 32-bit x86 emulators.
   Use only if the x86_64 APK does not install in LDPlayer.

Important:
- Before installing another build, delete the old Codex Android app from the phone/emulator.
- After installing, log in again with the Login button.
- If the app opens but Codex exits with code 134 in LDPlayer, install the LDPlayer x86_64 build instead of the ARM64 build.
- The 32-bit ARM build for very old phones, armeabi-v7a, is not included yet: one Codex dependency does not compile for this target.
